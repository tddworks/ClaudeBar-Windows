# Tools in WSL, phase 1: Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build phase 1 of [the WSL design](2026-11-03-wsl-design.md): a WSL distro's tools on the HUD, the Limits page and in Settings → Tools in WSL, read by `claudebar-probe` inside the distro, shipped beside `ClaudeBar.exe`. Not the Leaderboard: the uploader sends this PC's days only, as now.

**Architecture:** The HUD's portable Swift moves to a target of its own, `ClaudeBarShared`, which `native/` builds for Windows and `linux/` builds for Linux as `claudebar-probe`. The probe answers one `ProbeReading` as JSON. On Windows, Swift (`ClaudeBarWindows`) lists the distros, launches the probe through `wsl.exe`, and merges each distro's answer into the HUD's reply, so `cbw_hud_reading` keeps its shape. The C# app draws it, keeps each distro's switch and last reading in `app.json`, holds the distros' mutexes before an update, and ends the probes before an uninstall.

**Tech Stack:** Swift 6.3.3 (ClaudeBarKit at the pin `da68b4a3`), Glibc on Linux, WinSDK on Windows; C# / WinUI 3; Swift Testing; MSTest; GitHub Actions (`windows-latest`, and `ubuntu-latest` in `swift:6.3.3-noble`); Velopack 1.2.161; Windows PowerShell 5.1 for the PC checks.

## Where the design turned out not buildable as written, and what this plan does

1. **A target outside its package.** SwiftPM refuses a target whose path is outside the package root, so `linux/` can't name `native/Sources/ClaudeBarShared` as its own target; the spike linked each file. This plan has `linux/Package.swift` depend on `native/` by path and use its `ClaudeBarShared` product. Checked on a Mac (Swift 6.4.2): a package that depends by path on a local package whose executable target has `unsafeFlags` builds and runs, as `native/`'s `ClaudeBarUpload` has. Both manifests pin ClaudeBar by `revision`; SwiftPM refuses two different revisions of one package, so the two builds can't drift apart.
2. **The mutex and `async`.** A Windows mutex belongs to the thread that took it, and an `async` function can resume on another thread, so `ReleaseMutex` would fail. Each probe run holds its distro's mutex on a thread of its own and runs `wsl.exe` with blocking waits there (Task 13).
3. **The roots of a definition.** No public API in ClaudeBar lists the files a definition's data sources read: `Paths` is internal, and the sources are nested enums. `ProviderRoots.of` encodes the filled `[DataSourceDefinition]` and `UsageLog.Definition` (both `Codable`) and takes the path-shaped strings under `path`, `file`, `files` and `glob`. Tests pin the roots of Claude, Codex, omp and OpenCode Go, so a change in the encoding fails CI (Task 4).
4. **The shell's environment.** With `-e` and no shell, a `CODEX_HOME` or `CLAUDE_CONFIG_DIR` exported only in `.bashrc` never reaches the probe, and `DataSources.expandPath` reads the process environment only (`DataSources.swift:19-24`). The probe would read `~/.codex`, and the shared-root check would compare the wrong roots. The design's rejection of the share-based reading also implied the probe sees that environment; with `-e` it doesn't. This plan adds the environment import (Task 8, and *The environment* in the design, fixed in this PR). ClaudeBar's `LoginShellEnvironment` can't be reused for it: it runs one shell per variable (`value(ofEnvVar:)`, with the name inside the command), so the probe asks the shell once for every name.
5. **`$HOME` on Linux.** `FileManager.homeDirectoryForCurrentUser` follows `/etc/passwd`, not `$HOME` (research: `home` `/root`, `$HOME` `/github/home`), so the runner tests can't point the probe at a fixture home with `HOME=`. They make a user (`useradd`) and run the probe as that user, as `wsl.exe -e` runs it as the distro's default user.
6. **Zombies on the runner.** In a GitHub container job, PID 1 is `tail -f /dev/null`, which doesn't reap orphans, and a zombie still answers `kill -0`. The Linux job runs its container with `--init`.
7. **`wsl.exe`'s encoding.** `wsl.exe -l -q` writes UTF-16LE (research), but UTF-8 when `WSL_UTF8=1` is set, which a person may have set for the whole account. The parser reads both.
8. **The fallback drive rule.** With mountinfo unreadable, the design takes the root of `wslpath -u 'C:\'` without its letter. When drives are at `/c`, that's `/`, and every path would be under a drive. This plan reads the fallback as "the folder, then a one-letter name": `/mnt/c/...` and `/c/...` are drives, `/mnt/wsl` and `/home` aren't (Task 7).
9. **"Linux can't read that source at all".** The only signal is the text ClaudeBar's `Unavailable` writes (`DataSources/Sources/Internal/Unavailable.swift:28`, *… isn't available on Linux yet.*). The merge drops a failure whose message has those words, with a test pinning them (Task 5).

### The probe's command line (Slice B; Slice C builds it)

```
wsl.exe -d <distro> -e env CLAUDEBAR_WSL_RUN=<id> <probe> --json --windows-roots <file> --deadline 60
wsl.exe -d <distro> -e env CLAUDEBAR_WSL_RUN=<id> <probe> --logs-only --windows-roots <file>      (phase 2)
wsl.exe -d <distro> -e <probe> --end <id>
wsl.exe -d <distro> -e <probe> --end all
wsl.exe -d <distro> -e wslpath -u <Windows path>
```

- `<id>`: 32 lowercase hex digits. `<probe>`: `wslpath -u` of `<folder of ClaudeBar.exe>\linux\x64\claudebar-probe`. `<file>`: `wslpath -u` of `%LOCALAPPDATA%\ClaudeBar\wsl`, then `/windows-roots-<id>.json`.
- Stdout: one `ProbeReading` (exit 0), or nothing. Exit 1: bad arguments or an I/O error, the reason on stderr as `claudebar-probe: <reason>`. Exit 2: no answer 60 s after the deadline. Exit 3: no marker.
- The roots file is a `WindowsRoots`.

### The C interface (Slice C; Slice D calls it)

```swift
// cbw_hud_reading and cbw_hud_refresh: their replies gain "wsl".
@c public func cbw_wsl_configure(_ kept: UnsafePointer<CChar>?, _ context: UnsafeMutableRawPointer?, _ callback: CBWCallback?)  // {state}
@c public func cbw_wsl_end_all() -> Int32   // synchronous: distros swept, or -1 when wsl.exe couldn't list them
```

The reply's `wsl`:

```json
{"installed": true,
 "distros": [{"name": "Ubuntu-26.04", "running": true, "on": null, "probing": false,
              "answeredAt": 1762230000, "reading": {"version": "0.2.0", "...": "a ProbeReading"},
              "error": null}]}
```

`cbw_wsl_configure`'s argument, and `app.json`'s `wsl` key, the same shape:

```json
{"Ubuntu-26.04": {"on": true, "answeredAt": 1762230000, "reading": {"...": "a ProbeReading"}}}
```

- `on`: `true` or `false` once the person sets the switch; missing until then. Swift probes a running distro unless `on` is `false`. Settings shows the switch on when `on` is `true`, or missing with tools in the last reading.
- New problem kind in the HUD's reply: `notRunning`, message empty; the app writes *WSL isn't running · numbers from HH:mm* from the tool's `readAt`.
- The per-distro mutex: `Local\ClaudeBar.wsl.<distro>` on both sides.

```swift
import DataSources
import Foundation
import Providers

/// The places a provider's default login is read from, on one side
/// (docs/plans/2026-11-03-wsl-design.md, Folders shared with Windows): its
/// account folder and the files its data sources read (`credentials`), and
/// the folder of its usage records before the first wildcard (`logs`),
/// expanded as ClaudeBar expands them (`DataSources.expandPath`).
///
/// ClaudeBar has no public list of the files a definition reads, so the
/// definition's own encoding is read: the path-shaped strings under `path`,
/// `file`, `files` and `glob`. ProviderRootsTests pins the result.
public struct ProviderRoots: Codable, Equatable, Sendable {
    public let provider: String
    public let credentials: [String]
    public let logs: [String]

    public init(provider: String, credentials: [String], logs: [String]) {
        self.provider = provider; self.credentials = credentials; self.logs = logs
    }

    public static func of(_ definition: ProviderDefinition, homeDirectory: URL,
                          environment: @escaping @Sendable (String) -> String?) -> ProviderRoots {
        let values = definition.defaultAccountValues
        let expand = { DataSources.expandPath($0, homeDirectory: homeDirectory, environment: environment) }
        var credentials = values[ProviderDefinition.Accounts.folderValue].map { [$0] } ?? []
        if let sources = try? definition.dataSources(forDefaultAccount: values) { credentials += paths(in: sources) }
        let logs = definition.usageHistory(forDefaultAccount: values).map { paths(in: $0) } ?? []
        return ProviderRoots(provider: definition.id,
                             credentials: unique(credentials.map(expand)),
                             logs: unique(logs.map(expand).map(folderBeforeWildcard)))
    }

    static let pathKeys: Set<String> = ["path", "file", "files", "glob"]

    static func paths(in value: some Encodable) -> [String] {
        guard let data = try? JSONEncoder().encode(value), let tree = try? JSONSerialization.jsonObject(with: data) else { return [] }
        var found: [String] = []
        func walk(_ node: Any, key: String?) {
            switch node {
            case let object as [String: Any]: for (name, child) in object.sorted(by: { $0.key < $1.key }) { walk(child, key: name) }
            case let list as [Any]: for child in list { walk(child, key: key) }
            case let text as String where key.map(pathKeys.contains) == true && looksLikePath(text): found.append(text)
            default: break
            }
        }
        walk(tree, key: nil)
        return found
    }

    /// A place, not a JSON path or a value: home, absolute, a variable, the
    /// platform's app data, or a drive; never one still naming an account value.
    static func looksLikePath(_ text: String) -> Bool {
        guard !text.contains("{{account.") else { return false }
        if text.hasPrefix("~") || text.hasPrefix("/") || text.hasPrefix("${") || text.hasPrefix("{{platform.appData}}") { return true }
        let chars = Array(text)
        return chars.count >= 3 && chars[0].isLetter && chars[1] == ":" && (chars[2] == "\\" || chars[2] == "/")
    }

    static func folderBeforeWildcard(_ path: String) -> String {
        guard let star = path.firstIndex(where: { $0 == "*" || $0 == "?" || $0 == "[" }) else { return path }
        let before = path[..<star]
        guard let slash = before.lastIndex(where: { $0 == "/" || $0 == "\\" }) else { return String(before) }
        return String(before[..<slash])
    }

    private static func unique(_ paths: [String]) -> [String] {
        var seen = Set<String>()
        return paths.filter { seen.insert($0).inserted }
    }
}
```

```swift
import Foundation

/// Whether a WSL source and a Windows one are the same place (design,
/// Folders shared with Windows). Both sides in Windows form, normalized:
/// the `\\?\` prefix `GetFinalPathNameByHandleW` returns removed (`\\?\UNC\`
/// becomes `\\`), `\\wsl$\` read as `\\wsl.localhost\`, case ignored, `\`
/// and `/` the same, no trailing separator. A credential root is shared
/// only when it's the same place as a Windows credential root; a log root
/// when it and a Windows log root are the same or one is inside the other.
public enum SharedRoots {
    public struct WslRoot: Equatable, Sendable {
        public let kind: ProbeReading.RootKind
        /// The root in Windows form, or nil when it's under a drive mount that couldn't be mapped.
        public let windowsPath: String?
        public init(kind: ProbeReading.RootKind, windowsPath: String?) { self.kind = kind; self.windowsPath = windowsPath }
    }

    public static func normalized(_ path: String) -> String {
        var path = path.replacingOccurrences(of: "/", with: "\\")
        if path.hasPrefix(#"\\?\UNC\"#) { path = #"\\"# + path.dropFirst(8) }
        else if path.hasPrefix(#"\\?\"#) { path = String(path.dropFirst(4)) }
        if path.lowercased().hasPrefix(#"\\wsl$\"#) { path = #"\\wsl.localhost\"# + path.dropFirst(7) }
        return path.lowercased()
    }

    public static func isSame(_ a: String, _ b: String) -> Bool {
        let x = names(a)
        return !x.isEmpty && x == names(b)
    }

    /// The same place, or one inside the other, by whole names.
    public static func overlaps(_ a: String, _ b: String) -> Bool {
        let x = names(a), y = names(b)
        guard !x.isEmpty, !y.isEmpty else { return false }
        return x.starts(with: y) || y.starts(with: x)
    }

    /// Each WSL root left out: a credential root the same place as one of
    /// the provider's Windows credential roots, a log root overlapping one
    /// of its Windows log roots, or one that couldn't be checked. Counting
    /// nothing from a source beats counting it twice.
    public static func skips(provider: String, roots: [WslRoot], windows: ProviderRoots?) -> [ProbeReading.Skip] {
        var skips: [ProbeReading.Skip] = []
        for root in roots {
            let skip: ProbeReading.Skip?
            if let path = root.windowsPath {
                let match = switch root.kind {
                case .credentials: windows?.credentials.first { isSame(path, $0) }
                case .logs: windows?.logs.first { overlaps(path, $0) }
                }
                skip = match.map { .init(provider: provider, kind: root.kind, windowsPath: $0, reason: .shared) }
            } else {
                skip = .init(provider: provider, kind: root.kind, windowsPath: nil, reason: .uncheckable)
            }
            if let skip, !skips.contains(skip) { skips.append(skip) }
        }
        return skips
    }

    private static func names(_ path: String) -> [String] {
        normalized(path).split(separator: "\\").map(String.init)
    }
}
```

```swift
/// The drive mounts of a distro (design, PATH, The mount rule): each line of
/// /proc/self/mountinfo whose filesystem is drvfs, or 9p with aname=drvfs
/// among its options (split on `,`, then `;`). Its mount point, unescaped,
/// is the root; `path=` is the Windows folder it shows.
public struct MountTable: Equatable, Sendable {
    public struct Drive: Equatable, Sendable {
        public let point: String
        public let windowsRoot: String?
    }
    public let drives: [Drive]

    public init(mountinfo: String) {
        drives = mountinfo.split(separator: "\n").compactMap { line in
            let halves = line.components(separatedBy: " - ")
            guard halves.count == 2 else { return nil }
            let left = halves[0].split(separator: " ")
            let right = halves[1].split(separator: " ", maxSplits: 2)
            guard left.count >= 5, right.count == 3 else { return nil }
            let options = right[2].split(separator: ",").flatMap { $0.split(separator: ";") }.map(String.init)
            guard right[0] == "drvfs" || (right[0] == "9p" && options.contains("aname=drvfs")) else { return nil }
            let windows = options.first { $0.hasPrefix("path=") }.map { Self.unescape(String($0.dropFirst(5))) }
            return Drive(point: Self.trimmed(Self.unescape(String(left[4]))), windowsRoot: windows)
        }
    }

    /// The drive a path is on, by whole names; the longest mount point wins.
    public func drive(containing path: String) -> Drive? {
        let path = Self.trimmed(path)
        return drives.filter { path == $0.point || path.hasPrefix($0.point == "/" ? "/" : $0.point + "/") }
            .max { $0.point.count < $1.point.count }
    }

    /// mountinfo's `\ooo` escapes: `\040` a space, `\134` a backslash.
    static func unescape(_ text: String) -> String { /* octal triples after `\` to their byte */ }

    static func trimmed(_ path: String) -> String {
        var path = path
        while path.count > 1, path.hasSuffix("/") { path.removeLast() }
        return path
    }
}

/// Which paths are on a Windows drive: from the mount table, or, when it
/// can't be read, guessed from `wslpath -u 'C:\'`: that folder's parent,
/// then a one-letter name (`/mnt/c/` gives `/mnt/<letter>`, `/c/` gives `/<letter>`).
public enum DriveRule: Equatable, Sendable {
    case table(MountTable)
    case guess(cDrive: String)
    public func isOnDrive(_ path: String) -> Bool
}

public enum PathRule {
    /// `PATH` without the entries on a drive: WSL appends Windows' PATH, and a
    /// Windows npm install's extensionless shim would be found before a Linux tool.
    public static func withoutDrives(_ path: String, _ rule: DriveRule) -> String {
        path.split(separator: ":", omittingEmptySubsequences: true).map(String.init)
            .filter { !rule.isOnDrive($0) }.joined(separator: ":")
    }
}

public enum WindowsPath {
    /// A resolved Linux path in Windows form: on a drive, its mount's `path=`
    /// and the rest; on a drive without one, `wslpath -w`; on the distro's own
    /// disk, `\\wsl.localhost\<distro><path>`. Nil when a drive path can't be mapped.
    public static func of(_ path: String, rule: DriveRule, distro: String, wslpath: (String) -> String?) -> String?
}
```

### Task 8: The environment import

**Files:**
- Create: `linux/Sources/ProbeCore/EnvironmentImport.swift` (pure), `linux/Sources/ProbeCore/LoginShellRun.swift` (the process)
- Test: `linux/Tests/ProbeCoreTests/EnvironmentImportTests.swift`

The contract (design, *The environment*, added in this PR):

- **Which names:** every `${NAME` in the definitions the probe loads (`ProviderCatalog().detect()`: the bundled ones, and the person's own in the distro's `~/.claudebar`), with `LoginShellEnvironment.isValidName`, except `PATH`. Collected at startup from the definitions' own encoding, never listed by hand. ClaudeBar parses them in `Paths.expand` (`DataSources/Sources/PathPattern.swift:70-80`), which is internal and reads a `${` only at a path's start; this collector finds them anywhere in a definition, so a variable a definition uses in a setting counts too. At the pin: `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, `KIMI_SHARE_DIR`, `PI_CODING_AGENT_DIR`, `XDG_DATA_HOME`.
- **Never `PATH`:** the probe's `PATH` is its own, without the drives (Task 7's rule, applied before this import). A shell's `PATH` has WSL's Windows entries back in it, so a definition naming `${PATH}` would bring back the Windows shims the rule drops.
- **How:** once per run, `$SHELL` (or `/bin/bash` without one, as ClaudeBar's `LinuxProcesses.command(printing:between:and:)` chooses) with `-l -i -c 'env -0 > <file>; printf %s @@CLAUDEBAR_ENV_END@@ >> <file>'`. `<file>` is `env` in a folder the probe makes with `mkdtemp` (`$TMPDIR` or `/tmp`, mode 0700), named only from `[A-Za-z0-9/._-]` so it needs no quoting in bash, zsh or fish, and removed after. Stdin, stdout and stderr are `/dev/null`, in a process group of its own, 3 s. The file is opened by the command's own redirect, after the shell files have run, so nothing they print, nor anything they start in the background, holds it: what the shell files write goes to `/dev/null`. Core's `LoginShellEnvironment` asks one name per shell, reading stdout, and can't take a list.
- **Use:** each name with a non-empty value is `setenv` before any definition is expanded or any provider made, so `expandPath`, the CLIs (whose environment starts from the probe's, `LinuxProcesses.environment(for:_:)`) and the shared-root check all see the same roots.
- **Failure:** the run goes on with its plain environment, `environmentImport` is `failed` with the reason, and Settings says *Couldn't read your shell's settings; custom folders like CODEX_HOME may be missed*. It never says a custom folder was read when it wasn't.
- **Both modes:** `--json` and `--logs-only` import. A `--logs-only` run's days must come from the same folders as the HUD's; the cost is the shell's start, once per run (estimated below).
- **Nothing it starts outlives the run:** the shell and anything it starts carry the marker, so the probe's last step (Task 9) ends every process with its id.

```swift
public enum EnvironmentImport {
    public static let end = "@@CLAUDEBAR_ENV_END@@"

    public enum Outcome: Equatable, Sendable {
        case values([String: String])
        case failed(String)
    }

    public static func names(usedBy definitions: [ProviderDefinition]) -> [String] {
        var names = Set<String>()
        for definition in definitions {
            guard let data = try? JSONEncoder().encode(definition) else { continue }
            let text = String(decoding: data, as: UTF8.self)
            var rest = text[...]
            while let start = rest.range(of: "${") {
                let name = String(rest[start.upperBound...].prefix { $0.isASCII && ($0.isLetter || $0.isNumber || $0 == "_") })
                if name != "PATH", LoginShellEnvironment.isValidName(name) { names.insert(name) }
                rest = rest[start.upperBound...]
            }
        }
        return names.sorted()
    }

    /// `file` comes from `mkdtemp` with a safe template, so it needs no quoting.
    public static func command(shell: String?, file: String) -> [String] {
        let binary = (shell ?? "").isEmpty ? "/bin/bash" : shell!
        return [binary, "-l", "-i", "-c", "env -0 > \(file); printf %s \(end) >> \(file)"]
    }

    /// The file only `env -0` and the end marker wrote: anything else in it fails the import.
    public static func parse(_ file: Data, names: [String]) -> Outcome {
        guard !file.isEmpty else { return .failed("the shell wrote no environment") }
        var entries = file.split(separator: 0, omittingEmptySubsequences: false).map { String(decoding: $0, as: UTF8.self) }
        guard entries.last == end else { return .failed("the shell's environment ended before ClaudeBar's end marker") }
        entries.removeLast()
        let wanted = Set(names)
        var values: [String: String] = [:]
        for text in entries {
            guard let equals = text.firstIndex(of: "="), equals != text.startIndex else {
                return .failed("the shell's environment had an entry without a name")
            }
            let name = String(text[..<equals]), value = String(text[text.index(after: equals)...])
            if wanted.contains(name), !value.isEmpty { values[name] = value }
        }
        return .values(values)
    }
}
```

```csharp
/// Before *Update* quits for Velopack (docs/plans/2026-11-03-wsl-design.md,
/// An update): every distro's mutex, which waits for a probe the app or the
/// uploader runs, held on a thread of its own until the app exits. Windows
/// can't rename a folder a Linux program runs from, so an update during a
/// probe would fail. Best effort: an hourly upload can still start one
/// before Velopack renames.
internal static class WslHold
{
    internal static string MutexName(string distro) => $@"Local\ClaudeBar.wsl.{distro}";

    internal static Task TakeAll(IReadOnlyList<string> distros, TimeSpan timeout)
    {
        var taken = new TaskCompletionSource();
        var thread = new Thread(() =>
        {
            var until = DateTime.UtcNow + timeout;
            foreach (var distro in distros)
            {
                var mutex = new Mutex(false, MutexName(distro));
                try { mutex.WaitOne(Max(until - DateTime.UtcNow, TimeSpan.Zero)); }
                catch (AbandonedMutexException) { }
            }
            taken.SetResult();
            Thread.Sleep(Timeout.Infinite);   // held until the process exits, which releases them
        }) { IsBackground = true, Name = "WSL update hold" };
        thread.Start();
        return taken.Task;
    }

    private static TimeSpan Max(TimeSpan a, TimeSpan b) => a > b ? a : b;
}
```

## The environment import's cost

Not measured: the PC didn't answer on 2026-11-04. An estimate: a login shell of Ubuntu's stock `.bashrc` and `.profile` starts in tens of milliseconds; one that loads nvm, conda or a prompt framework, a few hundred milliseconds to a second. Against the measured 25 s of a warm `--json` run that is small; against a `--logs-only` run's 0.18 s of logs (phase 2) it can be most of the run, which is the price of reading the same folders the HUD reads. The 3 s timeout bounds it. Check 8 of `scripts/check-wsl.ps1` measures it; put the numbers in the PR and in research.md.
